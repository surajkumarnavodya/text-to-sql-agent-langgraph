# Database connectivity (config-driven -- see db/connection.py). SQLAlchemy
# is the engine abstraction; the actual driver used at runtime depends on
# DB_TYPE in .env. All four drivers below are listed so DB_TYPE can be
# switched without reinstalling anything -- it's harmless to leave the ones
# you're not using installed.
#
# Versions here are bumped above their "natural" latest-stable pin on
# earlier DB_TYPE drivers specifically because this machine only has Python
# 3.14 installed (see CLAUDE.md's Python-version note) and older pins have
# no cp314 wheel: pyodbc 5.2.0 and oracledb 2.5.1 don't publish one, so
# pip would otherwise try (and for pyodbc, fail) to build from source.

# app entirely, and is fixed by 2.3.3, the first pandas release with real
# Python 3.14 wheels.
